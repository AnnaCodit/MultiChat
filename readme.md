# MultiChat

Мультичат для стримеров, который объединяет сообщения Twitch, Kick, VK Видео Live и YouTube Live в одну ленту. Работает прямо в браузере — как обычная вкладка или как док-панель OBS Studio.

## Как использовать

1. Откройте [https://annacodit.github.io/MultiChat/](https://annacodit.github.io/MultiChat/) в браузере или добавьте этот адрес как док-панель в OBS/Streamlabs.
2. Укажите свои каналы в настройках и нажмите «Сохранить и подключиться».

Устанавливать расширения или отдельные программы не требуется.

Настройки сохраняются в браузере (или профиле OBS), поэтому на другом устройстве их нужно будет указать заново. При первом открытии в ленте показываются демонстрационные сообщения — они не взяты из реальных чатов.

## Возможности

- **Единая лента** для Twitch, Kick, VK Видео Live и YouTube Live с индикаторами подключения каждой платформы;
- **Нативные смайлики** Twitch и YouTube, а также 7TV, BetterTTV и FrankerFaceZ;
- **Бейджи** Twitch, Kick и YouTube;
- **Выделение сообщений**: избранные пользователи, лидеры рейдов, активные стримеры;
- **Умное сворачивание**: ответы чаттеров друг другу, сообщения ботов и сообщения с заданными ключевыми словами сворачиваются в кликабельную плашку, чтобы не засорять ленту;
- **Защита важных сообщений**: сообщения, адресованные стримеру, никогда не скрываются;
- **Отметка первого сообщения** зрителя за настраиваемый период;
- **Гибкая настройка ленты**: размер шрифта, лимит количества сообщений, скрытие бейджей;
- **Клик по нику** Twitch открывает профиль зрителя;
- **Фильтры**: игнорируемые пользователи и блокировка по ключевым словам.

## Известные особенности

- Некоторые платформы (например, VK Видео Live) могут обновлять ленту с небольшой задержкой.
- Подключение отдельных каналов Kick и YouTube может зависеть от доступности сервисов.
- Twitch IRC и WebSocket-соединения открываются браузером напрямую; запросы, которые платформы блокируют, проходят через вспомогательный прокси `https://fra3a.ru/tools/proxy/`.
